八周知识体系总结

阅读定位

本讲把八周知识整合为测量、变换、估计和评价的统一体系。依据包括《EMVA Standard 1288, Release 3.1》PDF第5–8、31–32页，《TOF Range-Imaging Cameras》“SPAD-Based Sensors”PDF第18、20、29页，《Time-of-Flight and Structured Light Depth Cameras》PDF第63、96、111、127–130页，以及《Camera Image Quality Benchmarking》PDF第113–115、256、335–336、367页。以下综合关系均标注为补充推导。

READ THE SOURCE

原文短摘 · 对照阅读

Camera Image Quality Benchmarking · §9.3 · PDF第336页
英文原文

“Using this formalism, it is important that the individual metrics produce values with the same units, for example, JND, otherwise combination metrics like the above will not provide relevant results.”

中文译读

采用这一形式时，各项指标必须产生具有相同单位的数值，例如JND，否则上述组合指标不会给出有意义的结果。

这句话怎么读

这是八周知识体系回到工程决策时的一条底线。不同数据域的DN、米、噪声标准差和质量损失不能直接放进同一个加权式；先明确被测量，再选择有依据的转换和用途。

原文信息与关键概念

原文信息：线性积分传感器把光子转换为电子和DN，SPAD将触发转为事件并依赖淬灭与恢复，结构光用三角几何，iToF用调制相位，ISP则把原始数据转成供使用或观看的图像。[emva PDF pp.5–6；spad PDF pp.18、20；depth PDF pp.63、96；benchmark PDF pp.113–115] ↗ 它们共同构成系统，但测量量、误差类型和评价尺度不同。

补充解释：八周学习可以归为四条贯穿关系。第一条是输入预算：有多少有用光子进入系统，背景占多少；第二条是信息转换：这些光子被如何变为电荷、事件、视差或相位；第三条是误差传播：随机涨落、系统偏差、空间和时间采样怎样影响输出；第四条是评价目标：输出究竟要忠实测量、好看、识别目标还是准确重建几何。

每条关系都需要边界条件。量子效率需要波长和面积基准，噪声需要时间和数据域，容量需要工作点，时间分辨率需要区分码宽与抖动，深度误差需要距离定义和参考，画质需要内容与观看条件。掌握这些边界比记住一个最佳数值更有迁移价值。

因此本课程没有把“高像素”“单光子”“HDR”或“低噪声”当作整体性能的替代词。它们描述某个机制或局部能力，必须进入具体任务的预算与验证流程，才有明确工程意义。

公式、单位与推导

KEY RELATION

同一尺度质量损失的Minkowski组合

原文公式 / 等价重述
ΔQm=[∑i(ΔQi)nm]1/nm
Camera Image Quality Benchmarking · PDF第336页 · 式(9.1)
符号物理 / 工程意义单位或量纲
ΔQi第i种属性的质量损失同一JND尺度
nm组合指数无量纲
ΔQm组合质量损失与输入一致的尺度

仅在各属性已转换到一致且有意义的质量损失尺度时讨论；这不是把任意相机规格或RGB-D误差直接相加的通用公式。

补充推导一：统一输入到输出的链路。在线性积分情况下，P→N=ηP→Sy=KN，效率与增益分别决定电子产出和数字尺度。[emva PDF pp.5–6, Eqs.(1)、(5)–(6)] ↗ 在低通量SPAD计数近似下，有用事件均值可写为Ns=PDEΦT，但死时间、后脉冲和串扰会破坏简单独立计数假设。[spad PDF pp.18、20、29；本式为补充预算] ↗

补充推导二：统一观测量到距离的传播。三角测量有δz≈z2δd/(bf)，相位测距有δρ≈cδϕ/(4πfm)，往返计时有δz≈cδτ/2。[depth PDF pp.63、96, Eqs.(2.6)、(3.14)；spad PDF p.9, Chapter 1 Eq.(1)] ↗ 这些关系把视差、相位与时间误差换到长度单位，实际不确定性还要由光子、背景、标定和场景机制决定。

原文评价公式：整体感知损失的Minkowski组合为ΔQm=[∑i(ΔQi)nm]1/nm，其中ΔQi为同一JND尺度上的属性损失，nm是无量纲组合指数；其选择需要感知数据支持，不能仅为改变排名而任意设置。[benchmark PDF p.336, Eq.(9.1)] ↗ 它不能直接接收电子噪声、毫米误差和色差的混合输入。单位统一与感知校准是使用前提，不是事后加一组权重就能代替。

补充解释：系统设计中可分别维护物理预算与评价模型：前者预测怎样采到信息，后者判断这些信息是否满足用途。物理性能改善可能被ISP抹去，感知改善也可能来自更合适的显示变换；二者要通过中间数据连接，而不应只看最终总分。

原图定位与分析

原图表定位与综合分析：EMVA图1在PDF第5页给出计量链，SPAD表1在PDF第29页拆分计时性能，深度图4.1在PDF第127页拆分偏差与精密度，图像质量教材的图7.11在PDF第278页展示相近PSNR的不同伪影。[各来源所列图表] 四者分别对应“测什么”“如何编码”“误差是什么”“对用途意味着什么”。

它们也揭示一种阅读方法：先确认坐标和单位，再确认样本或模型性质，最后判断结论可否迁移。机制示意图不自动给出器件规格，历史架构表不自动代表当前产品，模拟曲线不自动构成实验事实，特定图像的感知表现也不自动成为通用阈值。

对于原文可能存在歧义或印刷问题，学习笔记应明确保留疑点，避免为凑齐公式而自行编造编号或默默改写。对于教学中重新整理的公式，应说明是假设下的等价变换或补充推导。可追溯的解释比表面完整却无法核验的总结更可靠。

工程解释与性能关联

工程解释：今后面对一套新相机，可先收集数据定义、工作点与链路图，再进行四类检查。光学与采集检查输入、曝光和饱和；器件检查效率、噪声、计数或时间性能；算法检查颜色、深度、滤波和配准；评价检查客观属性、真实场景与任务接受条件。每一项结论都应能追到数据、模型或明确的工程假设。

面向可见光画质，可以从线性RAW确认电子预算，再检查ISP对噪声、颜色、纹理和伪影的取舍，最后固定观看条件比较。面向深度，可以先确认视差、相位或时间估计，再检查偏差、重复性、有效率、边缘和配准，最后验证真实几何任务。两个流程共享测量纪律，却保留不同输出目标。

系统迭代时，应以瓶颈为导向选择改动。输入不足时改善通量与效率；读出或背景占主导时改善对应噪声；偏差占主导时检查标定和场景机制；空间细节不足时检查光学、采样与处理。任何改动都需同时观察它可能损伤的另一项性能，例如曝光与运动、增益与容量、平滑与边缘、频率与范围。

原书最后强调，基准只是从有限内容预测使用表现，场景与用途选择决定结论价值。[benchmark PDF p.367] ↗ 因而学习完成并不意味着拥有一个永远正确的排名表，而是能够建立有边界的预算、提出可验证的解释，并在新的器件与系统上重复这一过程。

把知识体系用于下一次系统迭代

补充解释：原文短摘录“quality loss”意为画质损失，在PDF第336页用于说明属性损失的组合。它要求先说清相对什么参考、以什么尺度计算损失。这个要求与前面电子、相位和距离的计量纪律一致：没有参考和单位的分数不容易迁移。物理预算与感知损失可以共同支持决策，但二者不是同一坐标轴，不能用一个数字直接替代另一个。

面对新系统时，第一份记录应是一张变量关系表：场景输入由哪些可测量决定，传感器输出是什么格式，处理步骤改变了哪些统计性质，最终任务通过什么指标判断。这里的表并非固定某个厂商的管线，而是把实际数据流程画清。只要能够找到每项指标对应的数据阶段，就能避免把输出缩放误当灵敏度，把平滑误当精密度，把补洞误当完整测量，也能识别哪些量仍缺少观测。

第二份记录应是误差与失效清单。随机误差、稳定偏差、空间模糊、采样混叠、非线性裁剪、时间错位和无效数据分别需要不同证据。它们可能同时出现，但不应因输出都是图像就混为一类。对于每个重要现象，应注明在哪些条件下出现、哪些中间量跟随变化、何种改动预计有效，以及该改动可能损伤什么。这个清单把八周的公式转为下一轮可检验的设计问题。

第三份记录应保留独立验证边界。用于标定、拟合或参数选择的场景，不能完整代表将来使用情境；对于新光源、新材质、新温度或新运动，需要重新检查模型是否成立。可以沿用已经验证的计量关系，也应诚实保留超出验证范围的部分。系统知识的成熟表现，是知道何时可以用公式预测，何时必须补充观测，以及何时只能提出有条件的解释。

核心结论

八周知识的核心是把输入光子、器件转换、信号处理、误差传播和任务评价连成可追溯链路。不同技术应使用适合其输出的指标，再在统一任务条件下比较。持续记录定义、单位、工作点、原始依据和验证范围，才能把教材知识转化为可复现的系统判断，而不止停留在术语和规格数字。
