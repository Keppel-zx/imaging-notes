均值–方差关系与转换增益

阅读定位

主读EMVA Standard 1288 Release 3.1，第2.2节PDF第6页，第6.5—6.6节PDF第15—17页；公式(9)、(28)—(31)，图5、图6。对照Janesick《Photon Transfer: DN → λ》第4.1节PDF第42页，以辨别转换常数的相反方向。

READ THE SOURCE

原文短摘 · 对照阅读

EMVA Standard 1288 — Release 3.1 (30 December 2016) · §6.6 Photon Transfer Evaluation · PDF第17页
英文原文

“For color camera systems that use a color filter pattern any pixel position in the repeated pattern should be analyzed separately.”

中文译读

对于采用彩色滤光图样的相机系统，重复图样中每一种像素位置都应分别分析。

这句话怎么读

这给均值–方差拟合增加了一个重要条件：不要把不同CFA位置随意混成同一组统计。拜耳阵列中的两个绿色位置也可能需要分开，才能避免把通道差异混入增益或非均匀性。

原文信息与关键概念

英文短摘录。“Overall system gain”意为“整体系统增益”。本讲沿用这一原文术语，以下正文为独立中文解释。[emva PDF p.16] ↗

原文信息。均值—方差关系的核心不是“噪声越大相机越差”，而是在输入统计已知时，输出噪声随信号增加的速度携带了比例尺度信息。一个电子对应更多DN，光电子计数的随机波动也会被更强地映射到DN域。标准第2.2节利用这个关系，将系统增益定义为方差对扣暗平均灰度的斜率。[emva PDF p.6, Eq.9] ↗

需要区分两条回归。第一条是扣暗平均灰度对入射光子数，它给出响应度；第二条是扣暗后的时间方差对扣暗平均灰度，它给出系统增益。量子效率由两条斜率的比值获得。只测第二条曲线可以获得电子与DN的转换，却不能单独证明光谱量子效率，因为还不知道像素真正接收了多少光子。[emva PDF pp.16—17, §6.6] ↗

标准要求同一照射量下采集两幅图，并配套相同曝光时间的暗图。平均灰度由两帧共同估计，时间方差由逐像素差分的平方平均估计。这个方法借用大量像素替代大量时间采样，依赖平稳和均匀噪声假设。因而它不是所有相机模式下都成立的恒等测量方法；逐帧自动处理、相关噪声、明显闪烁都需要另行判断。[emva PDF p.15, §6.5—6.6] ↗

第6.6节规定，用零到百分之七十饱和信号范围的数据拟合响应度，并为增益选择同样范围。上限的意义是避开高亮压缩对斜率的影响，不是暗示所有相机在某个固定DN都进入非线性。对于不同位深、不同偏置、不同工作点，需要相对于各自有效饱和信号确定区间。[emva PDF pp.16—17] ↗

公式、单位与推导

KEY RELATION

均值–方差斜率就是 K

原文公式 / 等价重述
σy2−σy,dark2=K(μy−μy,dark)
EMVA Standard 1288 — Release 3.1 (30 December 2016) · PDF第16页
符号物理 / 工程意义单位或量纲
σy2−σy,dark2扣暗后的时间方差DN²
μy−μy,dark扣暗平均灰度DN
K系统增益DN/e⁻

这是§6.6对式(9)的扣暗重写，并不是新编号公式。均值轴与方差轴必须来自相同数据域；标准示例中用于回归的范围到约70%饱和。

原文公式。设图像有M行、N列，两帧为yA,yB。第15—16页式(28)、(29)给出 μy=12MN∑m,n(yA+yB),σy2=12MN∑m,n(yA−yB)2. 均值单位为DN，方差单位为DN²。差分估计以两帧同分布且互不相关为前提；若两帧均值漂移，平方差中也会包含漂移贡献，不能把全部结果都归为传感器噪声。

第6.6节把式(9)写成扣暗方差形式： V≡σy2−σy,dark2=KS,S≡μy−μy,dark,η=RK. 其中R为DN/入射光子，K为DN/电子。先减去暗方差，便去掉模型中的固定截距，使零截距拟合有明确物理含义。量子效率式(30)的分子、分母分别来自光子输入标定与噪声统计标定，二者共同完成从入射光到数字输出的闭环。[emva PDF pp.16—17, Eq.30] ↗

补充推导。对一组已扣暗的点，零截距最小二乘估计可写为K^=∑iSiVi/∑iSi2。这是基本回归展开式，不是标准单列的原始公式。式子解释了为何高信号点在未加权拟合中影响较大；若接近饱和的点已弯曲，即使看上去只有少量偏差，也可能显著改变斜率。

Janesick所用电子/DN常数记作g时，g=1/K。因此读到“增益增大”必须问作者采用哪个方向。器件的电压转换增益还可能以微伏/电子表示，它与包括后端模拟放大及ADC尺度的整体系统增益不是同一个量。[ptc PDF p.42, Eqs.4.3—4.5] ↗

原图定位与分析

原图定位。EMVA图5在PDF第16页，横轴是每像素入射光子数，纵轴是扣暗灰度；图6在第17页，横轴换成扣暗灰度，纵轴换成扣暗时间方差。读者应特别留意两个图的坐标并不相同：前者依赖光量标定，后者依赖统计量估计。两条直线的比值才得到量子效率。[emva PDF pp.16—17, Figs.5—6] ↗

图6标记了拟合区间、拟合线以及饱和位置。高信号处原始曲线偏离外推直线，说明不能把所有点硬塞进一个斜率。第12页说明这些示例评价图使用模拟数据，因此图中的曲线应理解为流程演示，而非对某款在售相机的实测性能证明。本讲仅分析图形结构，不将图中参数外推到其他设备。[emva PDF p.12；p.17, Fig.6] ↗

工程解释与性能关联

补充解释。系统增益标定能统一不同位深与模拟放大设置的结果。比如同一个输入电子噪声，在更大的DN/电子增益下会显示为更多DN；若只比较灰度标准差，会把放大尺度变化误判为器件退化。换算回电子域后，再检查饱和容量与量化项，才能判断该设置适合低照检测还是高亮动态范围。

然而换算不是万能修复。如果相机内部对两个绿色像素位置使用不同处理，混合统计可能产生额外散布。标准第17页要求彩色滤波阵列的重复位置分别分析，拜耳排列因此应分别处理两个绿色位置及红、蓝位置。即使两组绿色光谱近似相同，其偏置或读出路径也可能不同，先分开统计能避免把结构差异误当随机波动。

光源漂移是另一项关键限制。两幅图相减仅抵消不随帧变化的偏差，不能抵消亮度变化乘上像素响应的结果。若所有像素同时变化，差分平方中还会有整体均值偏差。应先识别漂移来源，而不是为了得到漂亮直线任意删除不符合预期的数据点。工作报告需保留剔除规则与原因。

最后应报告估计不确定度、拟合范围和工作点。标准图6要求以百分数给出增益的一倍标准差统计不确定度。统计拟合的不确定度并不覆盖光源标定、非线性或帧间相关等系统偏差；一条很平滑的拟合线也可能建立在错误模型上。因此可靠结果必须由模型条件、曲线形状和回归数值共同支撑。

测量边界的进一步解释

补充解释：统计误差如何进入选型。方差是由有限样本估计的，因此每一个曝光点都存在不确定度。像素数量很多并不保证所有样本独立，列相关、共同模式噪声或空间处理会降低有效样本量。回归得到很小的形式误差时，也应确认相关结构没有使统计置信度被高估。均匀照明和平稳噪声条件是测量方法成立的一部分。

增益换算还影响饱和容量。若把同一扣暗饱和DN除以较大的DN/电子增益，得到的电子容量较小。因此不正确的增益估计会让电子噪声和容量同时缩放，有时动态范围比值看似仍合理，掩盖了绝对尺度错误。用响应度与已标定光子输入交叉检查量子效率，有助于发现这种共同尺度问题。

在电子数极低且量化明显时，方差对信号可能不再呈理想连续关系。标准对暗噪声太小的情形要求报告上限，提醒我们不要给超出测量分辨能力的结果过多有效数字。降低读出噪声是器件能力，可靠地测出它又是另一个计量问题；两者需要分别判断。

工程报告最好同时保存原始统计点和参数摘要。摘要便于快速比较，原始点则可以检查拟合区间、削顶以及离群行为。若未来改变测量目标，例如从灵敏度比较转向非线性分析，保留完整曲线能够避免重新采集；只留下一个转换增益数值，则很难判断其适用范围。

核心结论

均值—方差斜率给出DN/电子尺度，响应度斜率再除以该尺度得到量子效率。扣暗、区分颜色位置、限制拟合范围和明确增益方向，决定结果能否被正确比较。
