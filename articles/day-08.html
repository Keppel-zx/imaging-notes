EMVA 1288 信号模型

阅读定位

本讲依据《EMVA Standard 1288: Standard for Characterization of Image Sensors and Cameras》，Release 3.1，2016年12月30日。精读第1节适用范围，PDF第4页；第2.1—2.3节线性信号、噪声与信噪比，PDF第5—7页；图1位于第5页。此文件的PDF页码与正文页脚页码相同。以下数字均表示这份已读取文件的页序。

READ THE SOURCE

原文短摘 · 对照阅读

EMVA Standard 1288 — Release 3.1 (30 December 2016) · §2 Sensitivity, Linearity, and Noise · PDF第5页
英文原文

“This section describes how to characterize the sensitivity, linearity, and temporal noise of an image sensor or camera”

中文译读

本节说明如何表征图像传感器或相机的灵敏度、线性度和时间噪声。

这句话怎么读

原句后附参考文献编号，本短摘保留其完整语义而省略编号。标准先建立信号和噪声模型，再由均值、方差测量辨认参数；空间非均匀性另在第4节处理。

原文信息与关键概念

英文短摘录。“Linear Signal Model”意为“线性信号模型”。本讲沿用这一原文术语，以下正文为独立中文解释。[emva PDF p.5] ↗

原文信息。标准把相机抽象成从入射光子到电子，再到数字灰度的线性系统。这个抽象不要求了解像素内部每一只晶体管，却要求被测输出满足相应假设。第1节明确针对线性光响应相机；噪声在所讨论范围内应满足时间和空间上的平稳、白噪声近似，各波长贡献可以线性叠加。因此，模型是一组带使用条件的测量规则，而不是给任何成品照片都可以套用的公式。[emva PDF p.4, §1] ↗

第2.1节的量子效率以整个像素占用面积为参考，包括填充因子与微透镜的作用。这个限定非常实际：同样写着量子效率，若一个数据以感光结面积为分母，另一个以完整像素面积为分母，它们未必可以直接比较。标准定义的输入是一个像素在一次曝光内接收的平均光子数，因而像素面积、曝光时间、辐照度和波长共同决定输入。光源的照度读数不能未经光谱换算直接替代光子数。[emva PDF p.5, §2.1] ↗

平均灰度中包含暗信号。扣除暗信号后，曲线斜率给出的是系统增益与量子效率的乘积，而非量子效率本身。系统增益负责把电子数映射成数字量，量子效率负责把入射光子映射成电子数；把两者混为一谈，就会把放大器增加灰度误认为传感器收集到了更多光子。标准随后用噪声统计识别增益，再从响应斜率中解出量子效率。[emva PDF p.6, Eq.6、9] ↗

噪声模型只保留光电子散粒噪声、等效输入暗噪声和量化噪声。这不是宣称其他噪声不存在，而是把读出和放大链路的随机影响合并为黑箱参数。标准的时间噪声模型尚未包含像素之间的响应差异，空间非均匀性放到第4节单独处理。同一幅图像的空间标准差不能自动当作这里的时间噪声。

公式、单位与推导

KEY RELATION

噪声方差与均值构成增益标尺

原文公式 / 等价重述
σy2=K2σd2+σq2+K(μy−μy,dark)
EMVA Standard 1288 — Release 3.1 (30 December 2016) · PDF第6页 · 式(9)
符号物理 / 工程意义单位或量纲
σy2输出时间噪声方差DN²
σd2输入暗噪声方差e⁻²
σq2输出量化方差DN²
K总体系统增益DN/e⁻
μy−μy,dark平均扣暗输出DN

在线性泊松模型里，扣暗平均信号越大，散粒方差按斜率K增长。常数项和斜率承担不同物理意义，空间固定图样不能直接混入时间方差拟合。

原文公式。第5页式(1)、(2)定义 η=μeμp,μp=AEtexpλhc. 这里η无量纲，μp是每像素每次曝光的光子数，μe是平均电子数，A用平方米，E用瓦每平方米，texp用秒，λ用米。先以AEt得到焦耳，再除单光子能量hc/λ，便得到光子数。这一步也说明：公式使用传感器表面辐照度，不是场景表面亮度。

第6页式(6)、(9)给出 μy−μy,dark=Kημp,σy2=K2σd2+σq2+K(μy−μy,dark). K的单位为DN/电子，σd为电子均方根，σy2为DN²；理想均匀量化近似下σq2=1/12 DN²。由电子泊松方差等于均值，先乘K2传播到输出，再用平均信号消去电子数，就出现方差对信号的一次关系。这里相加的是方差，不能把各噪声标准差直接相加。

补充推导。令S=μy−μy,dark，输出信噪比为S/σy。把分子分母同除K，便得到第7页式(11)的电子域表达式。增益从信号与模拟噪声中同时约去，唯有量化项保留1/K2。因此在量化已经足够细时，提高数字灰度尺度不能凭空改善入射端信噪比。这个结论以增益改变未引入额外噪声、未提前削顶为前提。

原图定位与分析

原图定位。PDF第5页图1同时画出相机物理链路和单像素数学链路。读图时应沿箭头区分两个变换：量子效率改变被探测事件的数量，系统增益改变电子在输出端对应的数值。图中各节点同时标出均值与方差，提示模型不仅预测平均亮度，还预测亮度波动。[emva PDF p.5, Fig.1] ↗

补充解释。图中的暗噪声与量化噪声加入位置不同。前者以输入电子计，经过增益后成为输出噪声；后者在数字转换处以DN计。若忘记加入位置，容易把同一个读出噪声既当输入噪声又当输出噪声计算两次。图没有给出镜头MTF、去马赛克或色调映射，不能用它解释所有JPEG画质变化。它的价值恰在于保留可识别参数，使平场统计能够反推出系统尺度。

工程解释与性能关联

补充解释。设定比较目标时，先固定输出层级。比较传感器，应尽量使用线性、未经过空间降噪的原始数据；比较成品相机，可以观察处理后图像，但需要另外建立非线性输出的解释。仅仅文件后缀是RAW也不能证明数据未经黑电平裁剪或坏点修补，应检查采集模式和相机设置。

还要固定增益、位深和温度等工作点。不同模拟增益下测得的系统增益本来就不同；若把低增益的饱和容量和高增益的最小暗噪声拼成一个性能点，将产生实际不可同时获得的参数组合。曝光变化时需要配套暗帧，因为暗信号可能随曝光增加。这个要求直接来自模型对平均暗项的保留。

检验模型最有价值的方式是同时检查两条线：平均信号对光子输入是否近似线性，噪声方差对平均信号是否近似线性。前一条异常可能涉及响应压缩或光源标定，后一条异常可能涉及帧间相关、处理或增益变化。两条都通过也只说明在当前范围内模型可用，不能证明镜头、颜色或运动性能优秀。把评价范围说清楚，才使一个准确的电子学指标成为可靠的系统判断。

对于关注器件性能和成像系统的读者，这种黑箱模型提供了合适的边界：不必从能带出发，却能识别量子效率、增益与噪声的不同作用。后续学习PTC、动态范围和非均匀性时，应始终回到“输入是什么、输出在哪一层、哪个统计量被测量”这三个问题。

测量边界的进一步解释

补充解释：输入标定与比较基准。单色光下使用一个波长即可把辐射能量换成光子数，宽带光则需考虑不同波长的光子能量和量子效率。把宽带光强全部放在某个名义波长，会改变输入计数的解释。标准采用受控光谱条件来表征效率，系统应用中还要考虑光源、滤光片、镜头透射与传感器响应的组合。一个可见光峰值效率不能代表近红外工作点。

同样需要区分像素输入与画面输入。模型中的面积是一个像素的面积，不是整个传感器面积。若两个相机像素尺寸不同，在同样辐照度和曝光下，其每像素光子数本来就不同。比较时可分别采用每像素光子、每面积光子或统一输出尺寸，但必须说明基准；不能在论证低照优势时悄悄更换分母。

读出噪声的电子单位也不是直接从灰度图上读出，而是经过系统增益换算得到。增益误差会同时传播到电子噪声、电子容量和量子效率结果，因此这些参数并非完全独立。若一次测量中多个电子域指标同时偏离预期，先核查转换尺度通常比逐一假设器件物理改变更有效。这是模型在工程排查中的另一项用途。

对暗信号还应区分平均偏置与随机波动。减去平均暗值能够修正平均输出，却不能消除曝光期间已经产生的随机暗电流事件。信号校正让零点正确，不等于噪声归零；同理，光响应归一化可以消除稳定比例差异，却无法恢复未被探测的光子。数学模型因此也帮助判断软件校正能够改进什么、受到什么限制。

核心结论

线性模型把光子探测效率、数值放大和随机波动分开。响应斜率只给出增益与量子效率的乘积，必须结合噪声统计才可分离；模型适用性与参数数值同样重要。
