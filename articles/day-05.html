SNR、动态范围与曝光

阅读定位

主读《EMVA Standard 1288, Release 3.1》§2.3–2.4和§6.6，PDF第6–8、18页；对照《Camera Image Quality Benchmarking》§4.3.4，PDF第108–111页。这里讨论线性采集端的信噪比与动态范围，显示端的色调压缩和HDR融合将在后续课程展开。

READ THE SOURCE

原文短摘 · 对照阅读

EMVA Standard 1288 — Release 3.1 (30 December 2016) · §2.3 Signal-to-Noise Ratio · PDF第7页
英文原文

“This means that the slope of the SNR curve changes from a linear increase at low irradiation to a slower square root increase at high irradiation.”

中文译读

这意味着SNR曲线从低辐照时的线性增长，转变为高辐照时较慢的平方根增长。

这句话怎么读

这里说的是未饱和线性模型中的两个渐近区间。读噪声占优时增加信号更有效，而散粒噪声占优后SNR只随计数平方根提高；不要把它与饱和裁剪后的下降混为一谈。

原文信息与关键概念

英文原文短摘录。“dynamic range”意为“动态范围”。在该标准中它是饱和输入与绝对灵敏度阈值的比，须与位深分开理解。[emva PDF p.8] ↗

原文信息：标准以扣暗平均信号除以输出时间噪声标准差定义SNR。高入射量时散粒噪声主导，SNR近似随光子数平方根增加；低入射量时底噪主导，SNR近似随光子数线性增加。[emva PDF pp.6–7, §2.3] ↗ 因而多收集同样比例的光子，在两个区段带来的收益不同。

动态范围是饱和入射量与绝对灵敏度阈值之比；绝对灵敏度阈值由SNR等于一确定。[emva PDF pp.7–8, §2.4] ↗ 这一阈值是可比较的计量定义，并不承诺该信号对应的图像已经足够美观，也不等于应用任务识别目标所需的对比或置信度。

教材提醒，动态范围可从保护高光后阴影仍能保留多少可区分细节来理解，而不仅是“高光不爆”。曝光通常可以减少到避免过曝，但阴影会随之更接近噪声底。[benchmark PDF p.108, §4.3.4] ↗ 这是容量与低噪声必须共同考虑的原因：仅增加上限而不改善下限，或仅压低底噪却过早截断，都限制明暗同时记录能力。

补充解释：SNR曲线描述指定工作点下不同入射量的质量，动态范围把整条可用输入区间压成一个比值。两个动态范围接近的相机，其曲线中间段、容量、效率或所需曝光仍可不同。阅读最终图像时还要考虑色调映射，它能够改变明暗的显示关系，但不能凭空恢复已经裁剪或淹没于噪声中的独立测量信息。

公式、单位与推导

KEY RELATION

把所有噪声放回同一输入域再比较

原文公式 / 等价重述
SNR(μp)=ημpσd2+σq2/K2+ημp
EMVA Standard 1288 — Release 3.1 (30 December 2016) · PDF第7页 · 式(11)
符号物理 / 工程意义单位或量纲
ημp平均光生电子数e⁻/pixel
σd输入等效暗噪声标准差e⁻
σq输出量化噪声标准差DN
K系统增益DN/e⁻
SNR信号与标准差之比无量纲

分母相加的是方差，不是标准差。量化项除以K²后才与电子域噪声同域；纯数字缩放不能凭空改善入射光子统计。

原文公式：标准给出SNR(μp)=ημp/σd2+σq2/K2+ημp。其中量子效率无量纲，μp为每像素平均光子计数，σd为输入电子噪声标准差，σq用DN表示。[emva PDF p.7, Eq.(11)] ↗ 总体增益在信号和噪声中大体抵消，剩余影响是量化噪声的输入等效项。

补充推导：令B=σd2+σq2/K2、N=ημp，则SNR=N/B+N。当N≪B时，近似N/B；当N≫B时，近似N。若其他条件固定而曝光翻倍，前者SNR接近翻倍，后者接近增加为原来的平方根二倍，前提是没有新增运动模糊或饱和。

令SNR等于一，得到二次方程N2−N−B=0，其正根为Nmin=(1+1+4B)/2，于是μp,min=Nmin/η。这是标准反函数式在SNR等于一时的补充推导，对应PDF第7页式(15)。不应在低噪声极限无条件用σd/η取代精确式。

标准动态范围DR=μp,sat/μp,min，并规定可用比值、20log10DR dB或log2DR bits表达。[emva PDF pp.8、18, Eq.(18)、§6.6] ↗ 这里bits是范围的对数表达，不是ADC有效位数。

原图定位与分析

原图定位与分析：EMVA图7位于PDF第18页，画出测量SNR、线性模型理论值、包含空间非均匀性的总SNR，以及量子效率为一且无暗噪声和量化噪声的理想曲线。两条竖虚线标记绝对灵敏度阈值和饱和入射量。[emva PDF p.18, Fig.7] ↗

读这张图应先区分“时间SNR”和包含空间不均匀的总SNR。高信号下即便时间散粒噪声的相对占比继续下降，PRNU仍可能使总SNR受限。图中的理想曲线使用入射光子数作横轴，故QE损失会直接体现为与理想情况的距离；若改用已生成电子数作横轴，效率的信息就被隐藏了。

标准PDF第12页说明这些例图来自模拟数据，图上的阈值不能引用为某款器件性能。可以引用其方法和坐标定义；若希望估算自己的系统，必须代入自己的量子效率、噪声和饱和输入量。教材图4.22在PDF第109页也显示高信号非均匀性可能形成平台，与此图构成机制上的对照。

工程解释与性能关联

工程解释：曝光时间既控制电子计数，也控制运动积分。为了提高低照度SNR延长曝光，可能同时降低运动清晰度，所以系统最优点不总是最大曝光。若运动约束已固定曝光，改善光圈、光学透过率、效率或读出噪声就更关键。若强光已使像素或ADC接近饱和，继续加曝光则可能丢失高光信息。

提高模拟增益的意义应分情况讨论。教材用前级和后级噪声说明，模拟增益可减小后级噪声折算到输入端的贡献，但也会使ADC在更少电子时饱和。[benchmark PDF p.111, Eqs.(4.13)–(4.14)] ↗ 因此“增益不改变SNR”只在理想统一缩放条件成立；真实系统应同时查看输入读噪、容量和高光余量。

对于特定任务，通常还需比SNR等于一更严格的条件。小对比度目标的可见性取决于目标与背景之差，而不是背景自身的平均亮度。即使全像素平均SNR很高，细节对比也可能被镜头或降噪削弱。本讲的SNR是基础计量，不能代替空间分辨率和感知评价。

动态范围报告应注明曝光、温度、增益、位深和标准版本。把不同工作点的最低噪声与最大容量拼接成一个“最佳动态范围”，会创造现实中无法同时实现的性能组合。

把曝光收益与任务约束放在一起

补充工程解释：若给定帧率和运动速度，最大允许曝光通常已经受到限制。这时比较两款器件，应在相同曝光下用相同输入量或等效系统条件计算SNR，而不是让某一相机任意延长曝光。若允许多帧合成，最终随机噪声可能降低，但运动对齐、场景变化和时延成为新的约束。多帧方法属于另一层系统设计，不能直接用来宣称单帧传感器的本征噪声改变。

动态范围也需要区分“输入跨度”和“可接受画质跨度”。标准选择SNR等于一作为最低阈值，使不同相机能按相同规则比较；实际任务却可能要求更高SNR。若把最低允许SNR提高，最低输入量增加，可接受跨度会缩小。其幅度取决于低信号处是读噪主导还是散粒噪声主导，因而不能只在标准动态范围上减去一个通用常数。

在保护高光的曝光设置下，阴影电子数相对减少。后续色调曲线可以让阴影显示得更亮，但随机涨落也被放大，且局部对比处理可能改变噪声的外观。如果只比较显示亮度一致的输出图而不记录曝光，就可能将渲染风格与采集端动态范围混为一谈。正确方法是同时说明线性输入的饱和与底噪，以及输出端采用何种色调和降噪策略。

另一个常见误区是把容量越大等同于任何亮度下画质越好。容量主要决定高信号端余量，低光工作点可能远未使用这些电子存储空间。相反，读噪很低也不保证明亮高反差场景有足够高光容量。把全曲线与任务输入分布叠加，能比单指标排序更清楚地看到实际瓶颈。

核心结论

SNR说明某个输入量下信号相对不确定性的大小，动态范围说明从规定最低可检测输入到饱和的跨度。曝光增加的收益由主导噪声决定，同时受运动与裁剪限制。dB和bits是表达方式，不能与ADC位数混淆。评价成像方案时，应把完整SNR曲线、容量和实际任务条件一起比较，而非只追求单个动态范围数字。
