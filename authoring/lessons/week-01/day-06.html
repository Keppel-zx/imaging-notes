第6讲 · CMOS Datasheet 解读

阅读定位

本讲依据《EMVA Standard 1288, Release 3.1》第10节及表2，PDF第31–32页，并回读§2.1–2.4与§6.5–6.6，PDF第5–7、15–18页。辅助理解使用《Photon Transfer: DN → λ》表1.1，PDF第9页。讲解对象是规格表的定义与可比较性，不提供未经核实的商业器件参数。

原文信息与关键概念

英文原文短摘录。“Sensor type”意为“传感器类型”。这是数据表必须说明的基本信息之一，但仅凭类型名称不能推断整机性能。[emva PDF p.31]

原文信息：EMVA要求公布数据性质，例如单件结果、典型值、保证值及寿命内保证值，并说明典型数据的样本选择与样本数量。传感器类型、有效阵列分辨率、像素尺寸、快门类型、读出与曝光能否重叠、最大读出速率和工作点也属于基本信息。[emva PDF p.31, §10.1] 这使规格表不只是一列最佳数字，而是一份带适用条件的测量声明。

表2列出需报告的主要性能量，包括量子效率、两种互为倒数的增益、暗噪声、空间非均匀性、最大SNR、非线性、绝对灵敏度阈值、饱和容量、动态范围及暗电流。[emva PDF p.32, Table 2] 其中一些量可在不同单位下呈现，阅读时要先统一输入端和输出端，不能凭数值大小直接排名。

标准要求每个工作点有自己的汇总和详细结果。[emva PDF p.32, §10.2] 因而同一相机的高速模式、低噪声模式、不同模拟增益和位深可能构成不同的性能组合。参数表中最小噪声与最大帧率若分别来自两个模式，就不能默认能够同时获得。

补充解释：一份规格可按三层阅读。第一层确认几何与时序是否满足任务，第二层确认光子与电子预算是否足够，第三层确认测量定义及条件能否与其他方案对齐。只看像素数和接口速度会漏掉噪声、容量与曝光限制；只看电子噪声又可能忽略运动失真和视场需求。

公式、单位与推导

原文公式：量子效率\(\eta=R/K\)，其中响应度\(R\)是DN/光子，总体系统增益\(K\)是DN/e⁻。[emva PDF p.17, Eq.(30)] 表2同时要求报告\(K\)及\(1/K\)，是为了使不同习惯的增益写法可换算，而不是把它们视为两个独立性能优势。

暗噪声换算式为\(\sigma_d=\sqrt{\sigma_{y,\mathrm{dark}}^2-\sigma_q^2}/K\)，量化噪声方差为\(\sigma_q^2=1/12\) DN²。[emva PDF p.17, Eq.(31)] 此式针对标准定义的输入端噪声，不能随意从低位深输出中减掉一个数后就认为获得了精确结果；标准对量化占主导的情况给出不能可靠估计及上界处理。

补充推导：若某一规格以e⁻/DN表示转换因子\(G\)，则\(K=1/G\)。输入等效的含量化暗噪声是\(G\sigma_{y,\mathrm{dark}}\)；若与不含量化的输入噪声比较，需要先确认双方采用相同定义。把标准差直接减去量化标准差不正确，应在方差域扣除再开方。

动态范围若以比值给出\(D\)，转换为dB用\(20\log_{10}D\)，转为二进制范围用\(\log_2D\)。最大SNR的散粒极限则约为\(\sqrt{\mu_{e,\mathrm{sat}}}\)。[emva PDF p.18, Eq.(33)及DR说明] 二者都可能写成dB，却描述不同量，不能把最大SNR数值当作动态范围数值。

原图定位与分析

原图表定位与分析：EMVA表2位于PDF第32页。它不是某个产品的测量结果，而是参数报告要求：量子效率需附光源中心波长和带宽，容量和灵敏度阈值可按电子、光子及单位面积输入表示，暗电流按每秒增长量报告。[emva PDF p.32, Table 2] 读表最有价值的动作是沿着单位追踪量的定义，而不是将所有百分比或分贝放到同一排序里。

同页正文要求汇总页同时给出PTC图6和SNR图7，原图分别在PDF第17和18页。PTC提供转换增益与饱和行为的证据，SNR曲线展示从弱信号到强信号的质量变化。只有一个读出噪声和一个容量数字时，曲线中间的非线性、异常拐点或可用区间可能被隐藏。

《Photon Transfer》表1.1位于PDF第9页，以绝对单位组织探测器性能。它提供另一种核查思路：问每个参数是否可换算到电子或光子预算。若规格只给相对DN、没有增益和条件，其跨设备可比性应保留判断，而不能自行补造缺失参数。

工程解释与性能关联

工程解释：首先审查快门定义。全局快门意味着所有像素同时开始与结束曝光，滚动快门按行错开开始时间但每行曝光时长相同，这是标准基本信息的明确区分。[emva PDF p.31] 对运动或闪烁场景，帧率相同仍可能出现不同几何或条带伪影。最高读出速率也必须与测量工作点一致，不能在改变模式后沿用原噪声值。

其次审查测试光谱与数据域。彩色拜耳阵列应分别处理重复单元内不同像素位置，标准举例包括两个绿色位置及红蓝位置。[emva PDF p.17, §6.6] 一个通道峰值QE不能代表整机白光效率，经过插值的RGB噪声也不能直接当作独立原始像素噪声。

再次审查温度、曝光和暗场处理。暗电流按电子每秒报告，而暗噪声是指定条件下的标准差，二者单位不同。若有暗电流补偿，均值可能几乎不随曝光变化，但随机涨落仍在；标准指出可使用方差随曝光变化的方法表征暗电流。[emva PDF p.8, §3.1]

最后，采购或方案比较需要把典型值与保证值分开。典型曲线适合判断总体趋势，保证值更适合构建最坏情况预算。缺少样本、温度或工作点信息时，应把缺项列为待确认，而不是用行业常见值填入并标记为已核实。

把规格表转成可比较的系统约束

补充工程解释：整理候选器件时，建议每一列只保留同一定义的量，并在相邻位置写清条件。例如把输入电子噪声、饱和电子容量和动态范围放在同一工作点，而把温度、曝光和增益放在该工作点的说明中。若某项条件缺失，应明确记作未知。未知不是性能差，但也不能被默认等于另一产品的条件，否则排序看似整齐，实际比较对象已经不同。

输入端指标与输出端指标还应分别保留。电子噪声有助于光子预算，DN噪声帮助检查采集和量化，最终图像噪声则包含ISP影响。同一相机在不同输出格式下可能呈现不同数值尺度，但只有结合转换增益才能判断输入等效噪声是否改变。位深、码值范围和有效动态范围三个术语不能互相替换。

饱和容量的来源也需要询问。标准采用数字输出的方差行为定义可用饱和入射量，并明确与物理满阱区分。[emva PDF p.7] 若另一规格用不同算法、不同阈值或不同增益测“满阱”，就应先核对其含义，再决定是否可与EMVA容量直接并列。没有原始曲线或方法说明时，可保留原指标名称，不宜擅自重命名为标准量。

最后还应把单器件数据与整机边界分开。镜头透过率、通道光谱、散热、时序和ISP可让同型号传感器在不同相机中产生不同表现。本讲训练的是审查定义的能力，目标是使采购、设计与测试使用同一套量纲和条件，而不是仅凭宣传页替整机画质下结论。

核心结论

数据手册是有条件的测量声明。先核查几何、快门、读出与工作点，再统一增益、电子噪声、容量和光谱定义，最后查看PTC与SNR证据。典型值不能自动当成保证值，不同模式的最佳参数不能任意拼接。能够解释每个指标的单位、测量条件和系统后果，才算完成对CMOS规格表的有效阅读。
